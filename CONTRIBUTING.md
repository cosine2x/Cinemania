# Contributing to Cinemania

## Commit messages

Use Conventional Commits for every commit. Write the subject as
`type: description`, with a lowercase type and a short description that starts
with a lowercase imperative verb.

| Type | Use for |
| --- | --- |
| `feat` | New functionality |
| `fix` | Bug fixes |
| `perf` | Performance improvements |
| `docs` | Documentation changes |
| `build` | Build, packaging, or release tooling changes |
| `chore` | Repository maintenance |

For example, use `fix: restore compatibility with TMInterface`.

When the reason for a change needs more context, add a blank line after the
subject and explain it in the commit body.
